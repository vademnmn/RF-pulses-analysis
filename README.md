# RF-pulses-analysis
RF pulse sequence simulation and frequency analysis with PyPulseq.

Description

This project explores the generation and visualization of radiofrequency pulse sequences used in magnetic resonance systems. The simulation focuses on RF pulse behavior without gradient fields and investigates signal structure, timing, and frequency-domain characteristics. RF pulse sequence simulation and visualization for MRI-related systems using PyPulseq, with potential applications in studying RF pulse interactions with biological tissues through JULIA-based sequence interpreters.

The implementation uses numerical methods to study pulse behavior and sequence organization in simplified MRI-related systems.

Frequency analysis

PyPulseq-based sequence modeling
