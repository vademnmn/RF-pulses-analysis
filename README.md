# RF-pulses-analysis
RF pulse sequence simulation and frequency analysis with PyPulseq. (no julia interpretation)

Description

This project explores the generation and visualization of radiofrequency pulse sequences used in magnetic resonance systems. The simulation focuses on RF pulse behavior without gradient fields and investigates signal structure, timing, and frequency-domain characteristics.

The implementation uses numerical methods to study pulse behavior and sequence organization in simplified MRI-related systems.

Features
RF pulse generation
Pulse sequence visualization
Frequency analysis
Configurable signal parameters
PyPulseq-based sequence modeling
